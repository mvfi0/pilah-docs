Example: `ask for review from <github-login> on PR <url>` It assigns the reviewer on GitHub and sends the review request to Discord. what is stacking?
Claude · 2026-09-22 07:23 UTC
**Stacking** (or "stacked PRs") means building your branch on top of **someone else's unmerged branch**, instead of on `staging`, so your PR depends on theirs. Normally every PR branches off `staging` independently: ``` staging ──┬── Aldo's branch (#18) └── your branch (#19) ``` Stacked, yours sits on top of his: ``` staging ── Aldo's branch (#18) ── your branch (#19) ``` **Why you did it:** both branches added a migration numbered `0011_` from the same parent `0010`. If both had merged into `staging` independently, Django would see two "latest" migrations and refuse to run `migrate`. Stacking on Aldo's branch let you renumber yours to `0012` and make it depend on his `0011`, so the chain stays a single line: `0010 → 0011 (Aldo) → 0012 (yours)`. **What stacking involves:** 1. **Rebase** your commits onto their branch, so your code includes theirs. 2. **Point your PR at their branch** (the "base"), so the PR shows only *your* changes, not theirs. 3. **Merge order is fixed:** theirs first, then yours. 4. **Afterwards**, point your PR back at `staging`. That was the "retarget" step. **The trade-offs**, which are useful to mention when explaining it: - ✅ It unblocks you now instead of waiting, and the conflict is resolved once, on purpose. - ❌ You depend on them: when Aldo pushed a new commit, you had to rebase again, and if his PR had been rejected, you'd have had to rework yours. - ❌ It needs extra steps and coordination (the rebases, the retarget, the merge order). **How it played out for you:** #18 merged on 21 Sep, you retargeted #19 to `staging` on 22 Sep, and now it's a normal PR again. The stack did its job and is gone. One-sentence version for an assessor: *"I stacked my PR on a teammate's unmerged branch because both added a migration with the same number; stacking let me renumber mine to follow his, keeping the migration history linear, then I retargeted to staging once his merged."*
